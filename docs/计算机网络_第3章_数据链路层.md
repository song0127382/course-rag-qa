# 计算机网络 第3章 数据链路层

## 3.1 数据链路层的功能与封装成帧

数据链路层在物理层提供的服务基础上,向网络层提供服务。主要功能:封装成帧、透明传输、差错检测。

封装成帧:在一段数据的前后分别添加首部和尾部,构成一个帧(frame)。首部和尾部的一个重要作用是进行帧定界,即确定帧的界限。帧的数据部分长度存在上限,即最大传送单元 MTU(Maximum Transfer Unit)。

透明传输:无论数据中出现什么样的比特组合,都能够按原样无差错地通过数据链路层。面向字节的链路(如 PPP)使用字节填充法(转义字符),面向比特的链路(如 HDLC)使用零比特填充法(发送端每遇到 5 个连续的 1 就填入一个 0)。

差错检测:目前广泛使用循环冗余检验 CRC(Cyclic Redundancy Check)。发送端根据约定好的生成多项式计算冗余码 FCS 并附加在数据后面;接收端对收到的帧做同样运算,余数为 0 则认为无差错。CRC 只能实现无比特差错的接受(无比特差错,不等于可靠传输)。

## 3.2 点对点协议 PPP

PPP(Point-to-Point Protocol)是用户计算机与 ISP 通信时使用的数据链路层协议。特点:简单;封装成帧(帧定界符 0x7E);透明性(字节填充);支持多种网络层协议;支持身份鉴别(PAP、CHAP);不使用序号和确认机制,不可靠传输;只支持全双工链路。

PPP 帧格式:首部包括标志字段 7E、地址字段 FF、控制字段 03、协议字段;信息部分长度不超过 1500 字节;尾部包括 FCS(使用 CRC)和标志字段 7E。

## 3.3 共享式以太网与 CSMA/CD

以太网(Ethernet)使用 CSMA/CD 协议(Carrier Sense Multiple Access with Collision Detection,载波监听多点接入/碰撞检测),要点:
1. 多点接入:许多计算机以多点接入的方式连接在一根总线上。
2. 载波监听:发送前先监听信道,信道空闲才能发送。
3. 碰撞检测:边发送边监听,一旦检测到碰撞立即停止发送,等待一段随机时间(截断二进制指数退避算法)后再次尝试。

争用期(碰撞窗口):2τ,即总线两端往返传播时延。以太网取 51.2 微秒为争用期,最短有效帧长规定为 64 字节,小于 64 字节的帧都是由于碰撞而异常中止的无效帧。

使用 CSMA/CD 协议的以太网只能进行半双工通信。

## 3.4 交换式以太网与以太网交换机

以太网交换机(switch)工作在数据链路层,实质是一个多端口网桥。它根据帧的目的 MAC 地址查找自身的交换表,把帧转发到对应的端口,端口间的通信是并行的,交换机内部无碰撞。

交换机的自学习算法:收到帧后,把帧的源 MAC 地址和进入的端口号写入交换表;若目的 MAC 地址在表中,则转发到对应端口;若不在表中(或目的地址是广播地址),则向除进入端口外的所有端口转发(洪泛)。

以太网交换机的两种交换方式:存储转发方式(可靠性高,时延较大)和直通方式(查到目的地址立即转发,时延小,不检测差错)。

## 3.5 MAC 地址与 MAC 帧

MAC 地址(物理地址、硬件地址)共 48 位(6 字节),固化在网卡的 ROM 中,全球唯一。前 3 字节是 IEEE 分配的组织唯一标识符 OUI,后 3 字节由厂家自行指派。

MAC 帧格式(以太网 V2):目的地址(6 字节)、源地址(6 字节)、类型字段(2 字节,标识上层协议,0x0800 表示 IP 数据报)、数据字段(46~1500 字节)、FCS(4 字节)。帧间还有 8 字节的前同步码(7 字节前导码 + 1 字节帧开始定界符),它不算入帧的正式长度。

适配器(网卡)接收帧时的过滤:目的地址为本站的帧、广播帧、多播帧(若加入多播组)被接受,其余丢弃。
