# 计算机网络 第1章 概述

## 1.1 计算机网络的定义与组成

计算机网络是由若干节点(node)和连接这些节点的链路(link)组成。节点可以是计算机、集线器、交换机或路由器等。网络之间还可以通过路由器互连起来,构成覆盖范围更大的互连网(internet)。

从工作方式上看,计算机网络可以划分为边缘部分和核心部分:
- 边缘部分:由所有连接在互联网上的主机(端系统)组成,由用户直接使用,进行通信和资源共享。
- 核心部分:由大量网络和连接这些网络的路由器组成,为边缘部分提供连通性和交换服务。

## 1.2 三种数据交换方式

电路交换:在通信之前先建立一条专用的物理通路,通信期间始终占用,结束后释放。优点是通信时延小、实时性强;缺点是线路利用率低,适合大量数据传输。

报文交换:将整个报文作为一个整体进行存储转发,不需要建立专用通路。线路利用率高,但报文大小不限时延较大。

分组交换(packet switching):把报文划分成若干较短的分组,每个分组加上首部(包含地址等控制信息),以分组为单位存储转发。它是互联网采用的核心交换方式,灵活、高效、迅速、可靠,但分组首部带来一定开销,且存在排队时延和丢包的可能。

## 1.3 计算机网络的性能指标

速率(bit/s):数据的传送速率,也称数据率或比特率。

带宽:在计算机网络中表示信道的最高数据率,单位 bit/s。

时延(total delay)由四部分组成:
1. 发送时延(传输时延)= 数据帧长度 / 发送速率,是主机或路由器发送数据帧所需的时间。
2. 传播时延 = 信道长度 / 电磁波在信道上的传播速率。
3. 处理时延:主机或路由器处理分组(检查首部、查找转发表等)所需的时间。
4. 排队时延:分组在路由器输入/输出队列中等待的时间。

往返时间 RTT(Round-Trip Time):从发送方发送数据开始,到发送方收到接收方的确认为止所经历的时间。

## 1.4 分层模型与协议体系结构

计算机网络的体系结构采用分层设计。分层的优点:各层之间相互独立、灵活性好、易于实现和维护、促进标准化工作。

OSI 七层体系结构(自上而下):应用层、表示层、会话层、传输层、网络层、数据链路层、物理层。

TCP/IP 四层体系结构:应用层、传输层(运输层)、网际层(网络层)、网络接口层。

五层协议体系结构(教学常用):
1. 应用层:通过应用进程间的交互完成特定网络应用,数据单位是报文。
2. 运输层:为两台主机中进程之间的通信提供服务,使用 TCP(面向连接、可靠)或 UDP(无连接、尽最大努力交付)。
3. 网络层:为分组交换网上的不同主机提供通信服务,把运输层产生的报文段封装成 IP 数据报进行传送,协议是 IP。
4. 数据链路层:把网络层交下来的 IP 数据报组装成帧,在相邻两个节点间的链路上传送。
5. 物理层:透明地传送比特流,规定电气特性、传输媒体接口等。

各层传递数据时使用的术语:应用层报文、运输层报文段(segment)、网络层 IP 数据报(datagram)、数据链路层帧(frame)、物理层比特(bit)。
